## "Stage 1": UI Form ##
  
  Create a UI with the following fields and store them in the list "meeting_4_tomorrow" for submitting to the backend:
    - AGENDA (Optional): It captures the meeting topic to be used further as below. Contains meeting agenda text. Call this text field as "meeting_4_tomorrow.AGENDA".    
    - COMPANY_INFORMATION (Optional): Contains company contextual information (Prospect Context) like requirement overview. Call this field as "meeting_4_tomorrow.COMPANY_INFORMATION".
    - PROSPECT_TECHNOLOGIES (Mandatory): Contains company technology related information. Tech platforms being used, IT team size, any tech initiatives. Limit this field for only tech information. Call this field as "meeting_4_tomorrow.PROSPECT_TECHNOLOGIES".
    - PROSPECT_INDUSTRY (Mandatory): Industry Domain of the prospect company. Call this field as "meeting_4_tomorrow.PROSPECT_INDUSTRY".
    - COUNTRY:(Mandatory) Country of the prospect company. Call this field as "meeting_4_tomorrow.COMPANY_COUNTRY". The drop down to have only these values only :"EMEA", "USA", "Australia", "Canada" & "UK". Default selection to be "USA"
    - MAX_MATCHES_CS (An adjuster with 10 as the max number and 1 as the minimum).
    - MAX_MATCHES_C (An adjuster with 10 as the max number and 1 as the minimum).

  //"Stage 1" Flow, calling the remaining steps
  Once the form containing the meeting is captured in the list variable "meeting_4_tomorrow", perform the following three actions upon form submission:
    Action 1: meeting_4_tomorrow.Perform Step 1: Case Study Matching;
    Action 2: meeting_4_tomorrow.Perform Step 2: Existing Client Matching;
    Action 3: meeting_4_tomorrow.Perform Step 3: Brand Matching;
        
  ### Step 1: Case Study Matching ###
    //Search the internal case study library for relevant case studies to recommend for the meeting.  
    meeting_4_tomorrow.PROSPECT_CONTEXT = meeting_4_tomorrow.AGENDA + meeting_4_tomorrow.COMPANY_INFORMATION + meeting_4_tomorrow.PROSPECT_TECHNOLOGIES;

    //This function is a reusable routine available in the SMO Python Package that we have built already.
   
    meeting_4_tomorrow.case_study_matching_result = find_casestudy_matches(
        prospect_context = meeting_4_tomorrow.PROSPECT_CONTEXT,
        prospect_industry = meeting_4_tomorrow.PROSPECT_INDUSTRY,
        prospect_technologies = meeting_4_tomorrow.PROSPECT_TECHNOLOGIES,
        max_matches = MAX_MATCHES_CS
    );

  ### Step 2: Existing Client Matching ###
    //Search the internal case study library for relevant case studies to recommend based on the prospect information. Call find_matches with the parameters as mentioned below. 
    
    //This function is a reusable routine available in the SMO Python Package that we have built already.
    meeting_4_tomorrow.existing_client_matching_result = find_matches(
        prospect_industry: meeting_4_tomorrow.PROSPECT_INDUSTRY,
        prospect_technologies: meeting_4_tomorrow.PROSPECT_TECHNOLOGIES, 
        prospect_country: meeting_4_tomorrow.PROSPECT_COUNTRY,
        max_matches: MAX_MATCHES_C
    );

  ### Step 3: Brand Matching ###
    //Suggest the brand name to use to the prospect
    meeting_4_tomorrow.brand_result = find_brand_match(
      prospect_industry = meeting_4_tomorrow.PROSPECT_INDUSTRY
    );
